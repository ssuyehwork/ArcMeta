# 复原重复添加提示全套功能与新增全部应用选项 —— 复原重复添加提示全套功能与新增全部应用选项.md

## 1. 任务背景
在拖拽导入与文件归类过程中，当导入的文件在资源库中已存在同名/同特征文件时，系统需要主动发起指纹与卡片查重，并向用户呈现可视化对比界面。

旧版本-7 中具备后台查重服务（`DuplicateDetectorService`）与对比弹窗（`DuplicateConflictDialog`），但在当前版本中尚未完整集成；同时用户提出需要在此界面底部新增一个 `[  ] 全部应用(N)` 复选框（如界面截图所示），支持一键将当前解决策略批量应用于后续所有冲突项。

本方案旨在复原全套查重与“重复添加提示”弹窗功能，并扩展“全部应用 (N)”批量决策机制。

---

## 2. 问题定位
1. **查重对比对话框缺失与 UI 差异**（对应用户原话：“将“重复添加提示”整套功能复原到当前版本”）：当前版本缺乏 `DuplicateConflictDialog` 对比视图（已存在 vs 新的文件卡片），且标题栏未显示冲突总组数（如 `重复添加提示 (8)`）。
2. **缺少“全部应用(N)”批量控制逻辑**（对应用户原话：“另外在这界面上新增一个“全部应用”选项”）：当存在多组重复文件（例如 8 组）时，旧版本只能逐个弹窗确认 8 次，缺乏一键将选择的策略应用到所有剩余冲突组的批量复选框。

```cpp
#include "DuplicateDetectorService.h"
#include "MetadataManager.h"
#include "CapsuleMediaExtractor.h"
#include "../util/DiskMediaExtractor.h"
#include <QFileInfo>
#include <QDir>

namespace ArcMeta {

std::vector<DuplicateConflictGroup> DuplicateDetectorService::detectDuplicates(const QStringList& newImportedPaths) {
    std::vector<DuplicateConflictGroup> conflicts;
    
    for (const QString& newPath : newImportedPaths) {
        QFileInfo newFi(newPath);
        std::wstring wNewPath = MetadataManager::normalizePath(newPath.toStdWString());
        
        // 检索是否存在具有相同文件名且大小一致的数据库已有项
        auto allCached = MetadataManager::instance().getAllCachedItems();
        for (const auto& [cachedWPath, rm] : allCached) {
            if (cachedWPath == wNewPath) continue;
            
            QFileInfo cachedFi(QString::fromStdWString(cachedWPath));
            if (cachedFi.fileName().toLower() == newFi.fileName().toLower() && cachedFi.size() == newFi.size()) {
                DuplicateConflictGroup group;
                
                // 1. 已存在项信息
                group.existingItem.folderId = QString::fromStdString(rm.folderId);
                group.existingItem.path = QString::fromStdWString(cachedWPath);
                group.existingItem.filename = cachedFi.fileName();
                group.existingItem.size = cachedFi.size();
                group.existingItem.thumbnail = CapsuleMediaExtractor::getCapsuleThumbnailReadOnly(QString::fromStdWString(cachedWPath));
                
                // 2. 新文件项信息
                group.newItem.path = newPath;
                group.newItem.filename = newFi.fileName();
                group.newItem.size = newFi.size();
                group.newItem.thumbnail = DiskMediaExtractor::getDiskThumbnail(newPath, 256);
                
                conflicts.push_back(group);
                break;
            }
        }
    }
    return conflicts;
}

} // namespace ArcMeta
```

## 6. 实现准则与预警【核心】

1. **复选框与数量动态绑定**：`m_chkApplyToAll` 的文本必须动态传入 `totalCount`（如 `全部应用(8)`），保证与 UI 截图 100% 对齐。
2. **批量决策跳过弹窗**：当 `batchApplied` 为 true 时，不再调用 `dlg.exec()`，实现 0 中断快速处理剩余重复项。
3. **安全物理清理**：对于选择“使用已存在”的项目，删除 `newItem.path` 并同步清理 `MetadataManager` 条目。
