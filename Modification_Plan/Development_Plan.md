# 0. 关于 ArcMeta 开发规则
## 0.1 必须职责单一，凡是这则不纯、不单一 则视为失败的

# 1. 关于 ArcMeta 整款应用
## 1.1 分为两种模式  “SQLite 内存模式” 和 “磁盘目录”模式
## 1.2 这两种模式运行时，各自都是独立运行 of，相互不干扰、井水不犯河水。

# 2. 关于“内容面板”显示数据的逻辑
## 2.1 内存模式（侧边栏分类）模式下，显示的逻辑应该是这样的（穿透）
例如，卡片里显示的缩略图应该是“1823760_thumbnail.png”，而卡片下方显示的名称应该是“1823760.psd”，不该显示“00mscw74m6001.arc”，卡片左上角也不该显示“DIR”，应该显示“psd”
G:\ArcMeta.Library_G\00mscw74m6001.arc\1823760.psd
G:\ArcMeta.Library_G\00mscw74m6001.arc\1823760_thumbnail.png

## 2.2 磁盘目录导航模式下，显示的逻辑应该是这样的（不穿透）
就是纯粹的目录导航，行为等同于 Windows 资源管理器 / Adobe Bridge。用户从地址栏或目录树打开任何路径，看到的就是这个路径下物理磁盘上原原本本的内容，不做任何解释、不做任何特殊语义翻译。哪怕打开的是 ArcMeta.Library_[盘符] 这个托管库根目录本身，看到的也就是里面原本的文件夹结构（包括所有 .arc 容器），跟打开任何一个普通文件夹没有区别。

# 3. 关于“侧边栏分类安全加锁与解锁”
## 3.1 物理级数据瞬间隐藏
当侧边栏分类被加锁（包含设置新密码、修改密码、立即锁定）时，内容面板必须通过清除底层模型数据机制（`m_model->clear()`），确保原展示的数据立马隐藏，不可显示出来。

## 3.2 卡片式内置无边框解锁视图
对未解锁的加密分类，移除阻断性模态解锁对话框，统一采用嵌入在内容面板中央的卡片式内置无边框解锁视图（`CategoryLockWidget`），提供输入密码验证功能。解锁成功后，自动通知侧边栏更新解锁图标并切换回常规数据视图。

## 3.3 密码保护子菜单功能项
侧边栏分类右键菜单“密码保护”包含：
- “设置”（未加密状态下可用）
- “修改”（已加密状态下可用，须先验证旧密码）
- “清除密码”（已加密状态下可用，须先验证旧密码）
- “立即锁定”（已加密且当前已解锁状态下可用）

# 4. 关于“空状态占位提示”
## 4.1 空白状态下的友好提示
在侧边栏托管分类为空，或者物理双击进入空物理文件夹时，内容面板正中央需通过优雅、低对比度的温和灰字（#888888）绘制显示“没有可显示的项目”。

## 4.2 列表视图组件的职责解耦
列表视图模式下的空文本提示由单独的 `DropTreeView::setEmptyHint` 接口配置。该机制通过接口参数控制绘制，不污染侧边栏自身所共用的 `DropTreeView` 实例，实现职责单一。
