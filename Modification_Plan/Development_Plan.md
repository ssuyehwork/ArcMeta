## [2026-07-31] 内存数据库唯一 ID 体系重构为 Base36 ID

- 用户描述的现象/问题：在跨分区物理移动、外接磁盘插拔或非 NTFS 分区等场景下，系统级的物理 fileId128 极其容易因为系统底层波动而产生断层与冲突，不利于数据的高可靠绑定。
- 用户期望的结果：将内存数据库模式的唯一 ID 体系由原本的系统级 fileId128 全面替换为由 ShellHelper::generateBase36Id() 生成的 13 位 Base36 字符串（即受控容器的目录名，如 00ms73182x000），磁盘模式则直接自愈退避原逻辑，互不交集。
- 本次任务边界：新建并编写 Modification_Plan-12.md 方案，定义卡片、元数据激活与 ID 同步映射流程。
- 不在本次范围内的：数据库基础建表结构的改动。
- 对应方案文档：Modification_Plan-12.md
